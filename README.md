# Do CLI ao Código — Projeto de Prática

Este repositório contém os exercícios e códigos que estou escrevendo ao acompanhar a série **"Do CLI ao Código"**, do professor [Gustavo Kalau](https://gustavokalau.com.br/do-cli-ao-codigo/). É um projeto pessoal de aprendizado, não um curso ou tutorial original — todo o crédito pelos conceitos, estrutura e abordagem de ensino é do autor original.

## Sobre a série

"Do CLI ao Código" é uma série do professor Gustavo Kalau voltada a ajudar quem quer usar a linha de comando a dar os primeiros passos ao começar a escrever seus próprios códigos em Python com o foco em automação de redes.

Você encontra o conteúdo original aqui:

- 🔗 [Site](https://gustavokalau.com.br/do-cli-ao-codigo/)
- 🔗 [Youtube](https://youtube.com/playlist?list=PLAtJZjyGUO2U&si=uVxjrcA2_Wybqc5Y)

## Objetivo deste repositório

Este é um espaço pessoal de prática onde eu vou:
- Resolver os exercícios propostos na série
- Fazer anotações sobre os conceitos conforme vou aprendendo
- Experimentar variações e pequenas extensões próprias dos exercícios

Este repositório **não** substitui o material original — se você tem interesse em aprender o mesmo conteúdo, recomendo acompanhar a série original diretamente.

## Como começar

```bash
# Clone o repositório
git clone https://github.com/badntwrkngnr/cli-ao-codigo
cd cli-ao-codigo

# Crie e ative um ambiente virtual
python -m venv .venv
source .venv/bin/activate  # em ambientes Windows: venv\Scripts\activate

# Instale as dependências
pip install -r requirements.txt
```
